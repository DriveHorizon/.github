# .github

What every Drive Horizon repository shares: the organization profile, the pull request and issue templates, the
Renovate preset, the security policy and the code of conduct. A change here reaches every repository at once, so merge
it only when the owner asks.

For a change across repositories, open one pull request per repository and merge the app first. The website states only
what is on `main` of the app.

Keep `profile/README.md` to what the app is, the repositories and the security policy.
